# Obsidian QMD Bridge
QMD Bridge for Obsidian.

## 실행/로그 설정

- **Dry-run 모드**: 설정에서 활성화하면 `Update`, `Embed` 실행 시 실제 작업은 건너뛰고 실행 예정 작업만 표시합니다.
- **로그 레벨**: `ERROR`, `WARN`, `INFO`, `DEBUG` 중 선택할 수 있으며 기본값은 `INFO`입니다.

## 변환 보고서 요약

`Update`, `Embed` 실행 후 진행 모달 하단에 아래 요약이 출력됩니다.

- 처리된 파일 수
- 성공/실패한 변환
- 경고/오류 개수
- 실행 시간
